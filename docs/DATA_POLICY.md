# Data policy

1. This repository holds code and public-data results only.
2. No clinical, institutional or patient-derived data, images, metadata or model outputs
   on such data are ever committed here.
3. If a clinical dataset is approved later, analysis on it happens in a separate private
   location, with approval and storage rules set by the institution. Only aggregate metrics
   approved for release may be added to this repo.
4. Public datasets are used under their own licences and are never redistributed here.
