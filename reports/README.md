# reports/

Aggregate results and figures generated by the notebooks. No images from the datasets and no patient-level data.

Everything here is regenerated by the notebook that produces it; if a file is not listed below, it is stale and can be deleted.

- `figures/aptos_resolution_vs_grade_heatmap.png`: grade mix inside each common resolution
- `figures/aptos_feature_grade_correlation.png`: Spearman correlation of each measurement with the grade
- `figures/aptos_metadata_correlation.png`: correlations between measurements
- `figures/aptos_metadata_pca_by_grade_and_resolution.png`: PCA coloured by grade and by resolution
